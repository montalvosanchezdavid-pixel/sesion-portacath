# Cuando el reservorio se infecta

**Ver la presentación:** https://montalvosanchezdavid-pixel.github.io/sesion-portacath/

- Introducción: anatomía, epidemiología, patogenia y biofilm, formas clínicas, diagnóstico (DTP) y tratamiento según germen.
- Caso clínico (ficticio) con decisiones para votar en directo.

Navegación: flechas ← → · `F` pantalla completa.
